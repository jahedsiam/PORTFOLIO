HOW TO ADD VIDEOS (no code, no links)
=====================================
Just upload .mp4 files here on GitHub (Add file > Upload files). The site updates itself in ~1 minute.

  videos/showreel.mp4            -> big hero showreel
  videos/reels/xxx.mp4           -> vertical 9:16 Reels row
  videos/product-videos/xxx.mp4  -> landscape card, filter tab "Product Videos"
  videos/ads/xxx.mp4             -> landscape card, filter tab "Ads"
  videos/explainers/xxx.mp4      -> landscape card, filter tab "Explainers"

- Any new folder you create becomes a new filter tab (folder name = category).
- File name = card title (lumio-launch.mp4 -> "Lumio Launch"). Start with 01-, 02- to control order.
- Format: H.264 .mp4, 720p or 1080p. GitHub web upload limit is 25MB per file.
- Once at least one video is uploaded, the sample cards disappear and only your videos show.
