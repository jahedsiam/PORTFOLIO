# Sahin portfolio

Static site (no build step). Edit `config.js` to change videos/photos, drop files into `videos/` and `images/`.
Connected to Vercel: every commit to `main` redeploys automatically.

Notes: GitHub's web upload accepts files up to 25 MB; larger videos need git push (up to 100 MB per file)
or an external host (Cloudinary, Bunny, Vercel Blob) - paste its .mp4 link as `url`.
